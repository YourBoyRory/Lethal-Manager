Mod manager for Lethal Company programmed in Python that focuses on making modding elegant for the Steam Deck when playing the game in Gamemode.
Uses mod packages downloaded from Thunderstore.io and is capable of managing BepInEx Modloader install automatically.
A no-bloat simple mod manager with a Windows, Linux, and SteamOS build you are sure to be able to use this on all platforms if you wish.
Theoretically, this should work on MacOS too.
